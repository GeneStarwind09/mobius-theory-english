# Play Mobius Theory with English subtitles — unofficial test patch

**Status: test release.** English subtitles and text-based story content are translated. Chinese artwork, including some puzzle and document images, remains. This is not yet a complete English localisation.

## What this patch does

Translates all six shipped subtitle files, along with choices, inner monologues, evidence descriptions, endings, puzzle instructions and many text-based menus. Original Chinese audio is preserved. You need your own installed copy of Mobius Theory, Steam app 1925830.

Supported Steam build: **9328697**, in-game version **1.0.20**. The installer checks the actual files and refuses unsupported builds.

## Installation

1. Download the complete English test patch ZIP from **[ADD RELEASE LINK AFTER HOSTING AND PLAYTESTING]**.
2. Extract all files into one folder. Do not run just the EXE from inside the ZIP.
3. Close Mobius Theory and open `Mobius-English-Patcher.exe`.
4. Select the installation folder. In Steam, use Properties → Installed Files → Browse if needed.
5. Click **Check Installation**, then **Install English** and wait for completion.
6. Launch normally through Steam. Enable subtitles in Settings if necessary (`字幕` in the original menu).

The patcher needs no Python installation or internet access. Keep the entire extracted folder together. Allow 1.5 GB of free space for backups and preparation.

## Uninstall / return to Chinese

Close the game, reopen the patcher, select the same installation folder and click **Restore Chinese**. Backups are stored inside the game's `.mobius-english` folder. Save files are not changed.

Steam's file verification restores the official game files and can remove the patch. Updates or other mods may make the file checks fail; don't force the patch over an unknown build.

## Known limitations

- Chinese text baked into images and movie frames remains. Some puzzle evidence may still require Chinese reading or assistance.
- The test release has not been checked through every branch and ending in live gameplay.
- Some diagnostic and legal text remains Chinese.
- Language switching is through installation/restoration, not an in-game selector.

## Reporting an issue

Include the chapter, scene or ending, what you clicked, and a screenshot if the issue concerns layout. For subtitle wording or timing, include the video filename and approximate timestamp. Avoid posting story spoilers outside spoiler tags.

This is an unofficial fan translation, not an official update from the developer or Valve. The download contains translation data and patch tools; original game videos and replacement copies of game assemblies/assets are not distributed.
